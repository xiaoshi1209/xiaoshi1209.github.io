# xiaoshi1209.github.io

我的个人主页，通过 GitHub Pages 发布。

## 本地预览

直接用浏览器打开 `index.html` 即可，纯静态页面，无需构建。

## 修改内容

- `index.html` 里的文字、标签、链接都可以直接改
- 改完提交到 `main` 分支，GitHub Pages 会在几分钟内自动更新

## 开启 Pages

仓库 Settings → Pages → Source 选择 `Deploy from a branch`，Branch 选 `main` / `/ (root)`，保存。
访问地址：`https://xiaoshi1209.github.io`
